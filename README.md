## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/MasterAY1/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view your site.

4. **Production Build**:
   ```bash
   npm run build
   npm run start
   ```
